# Roles and Personas

Based on the technologies and architectures present in the repos ecosystem, a well-rounded team to support and extend these projects would consist of the following roles/personas. These personas can be used to construct specialized AI Agents or hire human engineers.

## 1. The MCP Integration Specialist (AI/Tooling Engineer)
**Focus:** Connecting existing domains (games, rendering, web) to LLMs and agentic frameworks.
**Responsibilities:**
- Designing reliable MCP servers.
- Structuring context windows and RAG (Retrieval-Augmented Generation) pipelines.
- Ensuring AI tools are ergonomic, idempotent, and secure.

## 2. The Full-Stack Web Product Engineer
**Focus:** Building responsive, robust, and scalable web applications.
**Responsibilities:**
- Managing Monorepo architectures.
- Writing modern TypeScript, React, and Node.js.
- Connecting frontend UI to backend APIs and databases.
- Optimizing web vitals and user experience.

## 3. The Backend Systems Architect
**Focus:** High-throughput, scalable microservices and data pipelines.
**Responsibilities:**
- Writing performant Go and Python services.
- Containerizing applications with Docker.
- Defining clean API contracts (REST, gRPC, WebSockets).

## 4. The Interactive Media Developer (Game/Simulation Dev)
**Focus:** Real-time simulations, games, and rich interactive experiences.
**Responsibilities:**
- Utilizing Godot and Unity game engines.
- Writing physics, logic, and rendering code (GDScript, C#, C++).
- Managing large binary assets and game state.

## 5. The Embedded Hardware Engineer
**Focus:** Low-level device control and firmware.
**Responsibilities:**
- Writing memory-safe C/C++ firmware.
- Managing hardware interrupts, memory, and constrained computing resources.
- Interfacing hardware inputs/outputs to software layers.

## 6. The Principal Engineer / Review Agent
**Focus:** Code review, testing, validation, and architectural boundaries.
**Responsibilities:**
- Reviewing implementation branches for correctness against specs.
- Writing test plans and identifying missing edge cases.
- Enforcing deterministic simulation boundaries and architectural decisions (ADRs).
- Generating issue lists and critique without directly mutating production code.

## 7. The Planner & Security Assessor
**Focus:** Project breakdown, security reviews, and milestone definitions.
**Responsibilities:**
- Breaking down broad requirements into thin vertical slices or manageable milestones.
- Assuring that production-impacting work considers security, observability, and rollback capabilities.
- Ensuring external interfaces have clear, well-documented contracts.

## 8. The DevOps & Infrastructure Engineer
**Focus:** CI/CD pipelines, automated testing integrations, and environment stability.
**Responsibilities:**
- Designing and maintaining CI/CD pipelines for automated builds and test execution.
- Monitoring pipeline health, troubleshooting build failures, and resolving infrastructure bottlenecks.
- Providing support and standardized templates for environment setup, Docker configuration, and cloud provisioning.

## 9. The Market Research & Competitive Analyst
**Focus:** Market dynamics, competitor evaluation, and identifying strategic opportunities.
**Responsibilities:**
- Conducting in-depth market research to identify trends, audience needs, and total addressable market (TAM).
- Performing competitive product comparisons and capability teardowns.
- Providing data-driven insights to inform product positioning and feature prioritization.

## 10. The Product Marketing & GTM Strategist
**Focus:** Product positioning, messaging, and go-to-market execution.
**Responsibilities:**
- Crafting compelling product positioning and messaging that differentiates from competitors.
- Developing and executing comprehensive Go-To-Market (GTM) plans for new releases.
- Aligning engineering outputs with market-facing value propositions and launch timelines.

## 11. The Business Strategist
**Focus:** Business planning, monetization strategy, and growth modeling.
**Responsibilities:**
- Creating robust business plans outlining revenue streams, cost structures, and ROI.
- Evaluating monetization assumptions and ensuring the product achieves commercial viability.
- Assisting in investment pitches, strategic partnerships, and long-term ecosystem growth.
